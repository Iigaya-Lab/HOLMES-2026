# HOLMES Paper

Code for Hierarchical Latent Structure Learning through Online Inference (Aitsahalia, I. and Iigaya, K.) arxiv 2026, soon in _Neural Computation_. https://doi.org/10.48550/arXiv.2603.19139

## Overview

This repository implements particle filter-based inference for hierarchical and flat latent cause models using an extension of the nested Chinese Restaurant Process (nCRP). The code evaluates model performance on two synthetic tasks with hierarchical generative structure:

1. **transfer categorization task** - Multi-level hierarchical categories (2-5 levels). this is the basis for figures 2 and 3. The code in the transfer_task file was used to generate the results_f1_advantage_20260317_0908.pkl file used in the figures.
2. **Rule transfer task** - Forward transfer task. Models must apply learned rule to generalize to unseen stimuli. This is used for figure 4. The simulated data for the figure is in shape_color_transfer_20260612_115331_all_trials.csv, while the full parameter sweep in the supplement is in 'shape_color_sweep_20260611_2009_per_seed.csv', which can be generated by the shape_color_sweep_2 file.
