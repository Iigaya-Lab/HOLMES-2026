# HOLMES Paper

Code for Hierarchical Latent Structure Learning through Online Inference (Aitsahalia, I. and Iigaya, K.) arxiv 2026. https://doi.org/10.48550/arXiv.2603.19139

## Overview

This repository implements particle filter-based inference for hierarchical and flat models using the nested Chinese Restaurant Process (nCRP). The code evaluates model performance on two synthetic tasks with hierarchical generative structure:

1. **transfer categorization task** - Multi-level hierarchical categories (2-5 levels)
2. **Temporal context task** - Nested rule contexts with compositional structure
